# Сүхбаатарын хурд

Монгол хэл дээрх сугалааны платформ. Node.js 24+, Express, PostgreSQL, сервер дээр рендерлэдэг HTML болон өгөгдлийн сангийн зураг хадгалалт ашигладаг.

## Суулгах

1. PostgreSQL 16+ дээр хоосон өгөгдлийн сан үүсгээд `.env.example` файлыг `.env` болгон хуулж тохируулна.
2. `npm ci` ажиллуулна.
3. `node --env-file=.env migrate.js` ажиллуулж хүснэгтүүд болон анхны админыг үүсгэнэ. Нууц үг 14–160 тэмдэгт байна. Ижил нэвтрэх нэртэй бүртгэлийн нууц үгийг миграци солихгүй.
4. `node --env-file=.env server.js` ажиллуулна. Админ `/admin/login` холбоосоор нэвтэрнэ.

Production-д `NODE_ENV=production`, PostgreSQL-ийн TLS-тэй холболт, нийтэд ашиглах HTTPS `PUBLIC_ORIGIN` тохируулна. Reverse proxy-ийн тоог `TRUST_PROXY_HOPS`-д бодит сүлжээний бүтэцтэй ижил тохируулна. Миграцийн дараа админы анхны нууц үгийг runtime орчноос салгана. Процесс доторх IP rate limit нь нэг instance-д үйлчилнэ. Олон instance ажиллуулах бол ingress дээр хуваалцсан IP rate limit мөн тавина.

## Хавсаргасан Excel-ийг импортлох

1. Админаар нэвтэрч сугалаа үүсгэнэ. Нийт эрхийн багтаамжийг Excel-д өгсөн хамгийн өндөр дугаараас багагүй тохируулна.
2. Excel импортод `Sheet1` сонгоно. Толгойн мөр 0, эхлэх мөр 2, утас D, эрхийн дугаар A. Огноо, төлбөрийн дүн шаардахгүй. Нэг утас хэд хэдэн мөр дээр байвал тус бүрийн давхцаагүй эрх нийлж тоологдоно.
3. «Урьдчилж шалгах»-аар алдаатай болон давхардсан мөрүүдийг харж, «Импорт батлах»-аар зөв мөрүүдийг бүртгэнэ. Өмнөх эрхүүд хадгалагдана. Алдаатай багцыг импортын түүхээс буцааж болно.
4. Хэрэглэгч нүүр хуудсанд 8 оронтой утсаа оруулж нийтэд нээлттэй сугалаанд бүртгэгдсэн эрхийн нийлбэрийг харна.

Нийтийн хайлт зөвхөн тоо буцаадаг. Утасны эзэмшигчийг шалгах алхам байхгүй учраас дугаарыг мэддэг хүн уг тоог харах боломжтой. Гүйлгээ, утас, нэр, эрхийн дугаарыг админ хэсэгт хадгална.

CSV нь UTF-8 байна. Файлын дээд хэмжээ 5 МБ, нэг хуудасны дээд хэмжээ 10,000 мөр ба 80 багана.

## Шалгах болон нөөцлөх

- `npm run build` нь сервер ба браузерийн JavaScript файлуудын синтакс шалгана.
- `npm test` нь файлын гурван формат, админ, импорт, утасны дугаараар эрхийн тоо шалгах болон буцаалтыг ажиллуулна. `HURD_TEST_DATABASE_URL` өгвөл бодит PostgreSQL дээр тестийн тусдаа схем үүсгэнэ.
- PostgreSQL-ийн өдөр тутмын шифрлэсэн нөөц ба point-in-time recovery тохируулж, сэргээх дасгал тогтмол хийнэ. Нөөцөд зураг, утас, гүйлгээ болон аудит багтана. Backup болон DB хэрэглэгчдийн эрхийг серверийн орчинд тохируулна.
- Үйл ажиллагааны лог, SSL болон байршуулсан домэйн дээрх Facebook preview-г нээлтээс өмнө баталгаажуулна.

## Оролцогчдын зорилт ба Facebook

Сугалаа үүсгэх эсвэл засахдаа «Зорилтот оролцогчдын тоо» оруулна. Одоогийн тоог баталгаажсан эрхтэй давхардалгүй утасны дугаараар тооцно. Админы хаяг `/admin/login`. «Сайтын тохиргоо» дотроос холбоо барих Facebook хуудасны URL хадгална. Хуваалцах товч `PUBLIC_ORIGIN`-оор тохируулсан сайтын хаягийг ашиглана.
